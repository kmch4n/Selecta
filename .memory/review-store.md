# review-store — 苦手復習は内容ハッシュで永続化する

間違えた設問は `localStorage`（キー `selecta.review.v1`, `{ version, records }`）に貯める。
`index.astro` の `ReviewStore` クラスが担う（独立モジュールにはしない方針に従いインライン）。

- **識別キー = 内容ハッシュ**。`FNV-1a 32bit` を `NFC(問題文).trim()` ＋ 各選択肢の
  `NFC+trim` を区切り連結した文字列に適用し base36 化する。設問 `id` は使わない。理由:
  `id` はクイズ内でのみ一意で、別ファイルでも `q-1` が使われ**衝突する**ため。内容キーなら
  別タイトル・別ファイルの同一問題を同一視でき、id 衝突が別問題を誤って合流させることもない。
  代償として、問題文を編集すると別問題扱いになり履歴がリセットされる（許容済み）。
- **記録は確定回答ごとに `QuizApp.confirmAnswer()` の1フックだけ**。通常出題・復習・再挑戦は
  すべて同じ経路（`startQuizFromQueue`）を通るので、ここ1箇所で全モードをカバーできる。
- **自浄ルール**: 誤答で `weak=true`＋`wrong++`。正解で `weak=false`（レコードが既にある場合のみ）。
  **一度も間違えていない設問の正解は保存しない** — ストアを「苦手履歴」だけに限定するため。
  苦手リスト = `weak===true`。`wrong`（累計誤答）は統計として減らさない。
- **復習の再生**: `buildQuiz(records)` が保存ペイロードから合成 `QuizData` を作るので、
  元ファイルが手元になくてもホームから復習できる（＝本文もレコードに保存する理由）。
- **堅牢性**: 破損 JSON / localStorage 不可時は握り潰して空で起動し、通常出題は動かす。

方針の背景は `design.md` ではなくルートの `.codex/AGENTS.md`（Architecture 節）と実装計画にある。
